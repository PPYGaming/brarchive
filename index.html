                Embedded Payload Variant: MCB Compiled Binary JSON (\x7FMCB)
              

              

                Some official first-party Bedrock .brarchive files store pre-serialized C++ Cereal binary blobs starting with magic 7F 4D 43 42 (\x7FMCB) followed by u16 major, u16 minor, u32 patch. Because Cereal streams omit field names and rely on compiled C++ struct layouts, this converter detects MCB payloads, inspects their version header, and preserves them byte-for-byte without false modification.
